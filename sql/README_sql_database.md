# SQL Database Notes

## Database Name

uk_logistics_road_freight.db

## Database Type

SQLite

## Purpose

This database was created from the cleaned Department for Transport road freight and road traffic datasets.

The purpose of the database is to support SQL-based analysis of:

- UK road freight activity
- Goods lifted
- Goods moved
- Vehicle kilometres
- Regional traffic patterns
- Road type demand
- Vehicle type traffic
- HGV and logistics network activity
- Local authority traffic patterns
